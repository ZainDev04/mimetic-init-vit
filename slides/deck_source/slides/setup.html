Setup: written from scratch in plain PyTorch

Data

CIFAR-10: 50,000 train and 10,000 test images, 32 x 32, 10 classes. No validation set.

Model

ViT, width 192, depth 12, 3 heads, patch 2: 257 tokens, 5.34M parameters. Fixed sinusoidal position embeddings.

Training

AdamW, lr 3e-3, weight decay 0.01, batch 512, 100 epochs, RandAugment and Cutout. One T4 on Kaggle, about 2.3 h per run.

Our choices where the paper is silent

5 warmup epochs then cosine decay · RandAugment(2, 9) · Cutout 16 x 16 · random crop and flip · no dropout · float16 mixed precision · seed 0, one run per setting

3 / 7 · Code: model.py, mimetic_init.py, train.py

Three files. model.py: patch embedding is a convolution with kernel and stride 2, so 16 x 16 = 256 patches plus a class token. Pre-norm blocks, separate q, k, v and projection layers so mimetic init can set each one, MLP ratio 4 with GELU, head on the class token. Attention uses F.scaled_dot_product_attention: the same formula softmax(QK^T / sqrt(64)) V, but it does not store the 257 x 257 matrix; the hand-written version ran out of memory at batch 512. The self-test shows both agree to below 1e-6. mimetic_init.py: new Z1 per head, one Z2 per layer. Self-test: W_Q W_K^T diagonal +0.39 to +0.40 (below 0.7 because we keep only rank 64 of 192), W_V W_proj diagonal -0.40. train.py: learning rate set by hand every step, warmup then cosine. Base init is the PyTorch default for every layer. The paper does not state the schedule, the augmentation strengths, crop and flip, or regularization. These are our choices and are a likely source of the gap to the paper.
