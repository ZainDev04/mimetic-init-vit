4 / 7 · Test accuracy (%) on the 10,000 CIFAR-10 test images, fixed at epoch 100 before training

Base 85.13 against the paper's 86.07; mimetic 88.87 against 90.78. Gain 3.74 against 4.71, so 79% of the paper's gain. Why epoch 100 and not the best epoch: there is no validation set, so choosing the best test epoch would use the test set for model selection. We fixed epoch 100 before training. The best epochs are only 0.10 (base) and 0.06 (mimetic) higher. From the plot: mimetic is ahead for almost the whole run. Both runs had stopped improving; over the last ten epochs base stays between 85.00 and 85.22, mimetic between 88.75 and 88.93, so this is not under-training. Mimetic fits the training set better (94.80 against 94.13 train accuracy) and still has the smaller train-test gap (5.93 against 9.00), so it improves generalization as well as fitting.
