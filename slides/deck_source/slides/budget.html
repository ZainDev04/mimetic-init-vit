5 / 7 · One seed per setting. Two otherwise equal mimetic runs differ by 0.28, a rough noise level.

Question: does the gain depend on how long we train? The paper's ImageNet results hint that the gain shrinks with longer training (2.8 to 4.1 points in a 150-epoch pipeline, about 0.5 in the 300-epoch DeiT pipeline), but that comparison also changes batch size, augmentation and other settings. We changed only --epochs. Warmup stays 5 epochs, seed 0. Each run has its own cosine schedule, so a 25-epoch run is not the same as epoch 25 of a 100-epoch run: the separate 25-epoch mimetic run ends at 81.03, while epoch 25 inside the 100-epoch run was 75.16. Result: on CIFAR-10 the gain grows: +1.82, +2.42, +3.74. From 50 to 100 epochs base gains 1.15 points and mimetic 2.47; base is near its limit, mimetic keeps improving. This does not contradict the paper, because their longer ImageNet pipeline also differs in other ways. Limits: one seed. The rise from +1.82 to +3.74 is far above the 0.28 noise estimate; the step from 25 to 50 epochs (+0.60) is less certain.
